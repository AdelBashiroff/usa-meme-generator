# USA Meme Generator

Генератор мемов в американском стиле: 4 шаблона (классика, плакат «The Best ___ in America», Executive Order, Breaking News), живое превью и скачивание PNG 1080×1080.

Чистые HTML, CSS и JavaScript, мемы рисуются на Canvas. Без зависимостей и сборки — просто открой `index.html`.

Все фразы вымышлены и не являются реальными цитатами или новостями.
